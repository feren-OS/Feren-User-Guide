Reporting bugs
==================

Package dependency issues
-------------------------------------

.. hint::
    This section is for applications that say :guilabel:`Not Available` in Store and when installed through Terminal result in an error stating that :guilabel:`You have held broken packages`.

The best way to report dependency issues in Feren OS is through the `Dependency Issue Reporting bugtracker <https://github.com/feren-OS/Feren-OS-Dependency-Issue-Reporting/issues>`_.

Once there, and have made certain your issue hasn't already been reported, click `New issue` to begin reporting the dependency issue that you're encountering.


Application issues
-------------------------------------

If the application you're reporting an issue with came pre-installed with Feren OS, due to Feren OS's nature you should report the issue at the following places:

- Vivaldi: `Report a bug in Vivaldi <https://help.vivaldi.com/desktop/troubleshoot/reporting-a-bug-in-vivaldi>`_
- Koko, Krita, Okular, KDE Connect, KRDC, Kamoso, Merkuro, Ark, Calculator, KCharSelect, KWrite, Spectacle: `KDE Bugtracking System <https://bugs.kde.org>`_
- Web Browser Manager, Software Sources, Store, Update Manager, System Maintenance, Languages, Input Method, Login Window, Transfer Tool, Welcome Screen: `Feren OS Bug Reporting <https://github.com/feren-OS/Bug-Reporting-Center/issues>`_

Make sure your issue hasn't already been reported, provide adequate detail into the forms you're prompted to fill, and keep an eye out for any responses.

If the application you want to report having issues in is not listed in the above list, or is an application you manually installed, look for methods to report bugs inside the application, such as inside its :guilabel:`About` option. If there is no way to do so, look in the application's page in Store for any useful links and, failing that, search online for a way to report bugs to the application's developers.

.. hint::
    If you are not sure about where to report a bug, don't be afraid to `ask around <https://feren-os-user-guide.readthedocs.io/en/latest/help.html>`_ as others might know, from the application you describe or name, just what you want to report a bug for and where you can report the issue you have encountered at.


General Feren OS issues
-------------------------------------

If none of the sections above apply to your issue, you can report the issue you're having at the `Feren OS Bug Reporting Center <https://github.com/feren-OS/Bug-Reporting-Center/issues>`_. After you've made certain your issue hasn't already been reported there, click `New issue` to start reporting the issue you're encountering.
