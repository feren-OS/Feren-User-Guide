Sending Feedback
==================

The best way to send feedback about Feren OS is through the "Send Feedback or Report an Issue" application, which can be found at :menuselection:`Applications Menu --> System --> Send Feedback or Report an Issue`

Once you have opened the shortcut, your default browser will open up to the Feedback Center. From here, select :guilabel:`Contact me or submit a review of Feren OS` and choose to either :guilabel:`Contact` or :guilabel:`View Social Media Links`.

.. warning::
    If you need assistance, use the social media links instead of contacting me - the contacts mailbox is checked rarely and its use may be changed in the future to accommodate this.

Sending Feedback about applications
-------------------------------------

To send feedback about applications, look for methods to do so inside the application, such as inside its :guilabel:`About` option. If there is no way to do so, look in the application's page in Store for any useful links and, failing that, search online for a way to send feedback to the application's developers.
