Widgets
==================

Widgets are gadgets that you can add to the Desktop as well as to Panels.

To add a widget, you must enter Edit Mode by right-clicking the Desktop, or an empty part of a Panel, and selecting :guilabel:`Enter Edit Mode` in the menu that appears.

.. figure:: ../images/editmode.png
    :width: 1366px
    :align: center

Now you're in Edit Mode, click `Add Widgets...` to open the widget browser.

.. figure:: ../images/plasmoids.png
    :width: 1366px
    :align: center

From the widgets sidebar, you can:

* `Get New Widgets <https://feren-os-user-guide.readthedocs.io/en/latest/kns.html>`_ from the top-right of the sidebar
* Drag widgets to add them to the Desktop or a Panel
* Double-click a widget to add it to the Desktop


When finished, click the X button on the top bar to exit Edit Mode.


Managing widgets on the Desktop
-------------------------------------

To manage a widget on the Desktop, you have two options:

1. Enter Edit Mode and move your mouse onto the widget
2. Click and hold on the widget without moving it

If successful, resize handles and a grip with options will appear around the widget.

.. figure:: ../images/plasmoidoptions.png
    :width: 1366px
    :align: center

From here you can:

* Resize the widget
* Spin the widget
* Configure the widget
* Disable the background of certain widgets
* Remove the widget


Removing widgets in a Panel
-------------------------------------

To remove a widget in a Panel, you must:

1. Enter Edit Mode
2. Click on the settings button at the end of the panel the widget is inside
3. Hover on the widget
4. In the options that pop out of the widget, select :guilabel:`Remove`
