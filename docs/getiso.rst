Downloading Feren OS
==================

Going to the Feren OS Download Page
----------------

Before you can download Feren OS, you obviously need to go to the page where you can download Feren OS. The page can be accessed by clicking on the 'Get Feren OS' link at the top-right of the website.

Downloading Feren OS
----------------

Now you're on the download page, click the ``Download Feren OS`` button found to the right to proceed to the download page.

.. hint::
    Feren OS is a '.iso' file - if it is downloading slowly, try clicking the ``Problems Downloading?`` button on the page the download starts at in order to change the mirror you're downloading Feren OS from.
