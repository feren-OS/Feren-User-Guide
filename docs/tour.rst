Tour
==================

What is the Feren OS Tour?
----------------

The Tour is a built-in utility that guides you through the first stages of using Feren OS, including a few handy tips and tricks to get you familiar with Feren OS. It launches automatically when you log into Feren OS for the first ever time, but can be revisited at any time via :menuselection:`Applications Menu --> System --> Tour`.
